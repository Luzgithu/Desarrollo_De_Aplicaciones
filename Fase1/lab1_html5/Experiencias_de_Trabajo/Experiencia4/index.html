Experiencia de Práctica N.° 04: Metadata

En esta experiencia se estudian diferentes elementos de metadata utilizados dentro de la cabecera <head> de un documento HTML5.

A) Análisis de un ejemplo sencillo

El elemento <title> permite establecer el título del documento HTML.

El contenido del elemento <title> puede observarse en la pestaña del navegador.

En esta página se ha utilizado: 

            <title>Experiencia de Metadata HTML5</title>

B) Experimenta con la codificación de caracteres

En la cabecera del documento se estableció la codificación UTF-8 mediante: 

            <meta charset="UTF-8">

Ejemplo en japonés:

ご飯が熱い。

C) Uso de la descripción en los motores de búsqueda

La etiqueta <meta name="description"> permite proporcionar una descripción acerca del contenido de una página web.

En esta página se utilizó: 

          <meta
              name="description"
              content="Página desarrollada para la experiencia de práctica sobre metadata en HTML5..."
          >

D) Uso de Open Graph

Open Graph utiliza metadatos que permiten describir una página web cuando esta es compartida.

Las propiedades utilizadas en esta experiencia son:

  • og:title
  • og:type
  • og:image
  • og:url 
          <meta
              property="og:title"
              content="Experiencia de Metadata HTML5"
          >

          <meta
              property="og:type"
              content="website"
          >

          <meta
              property="og:image"
              content="https://example.com/imagen.jpg"
          >

          <meta
              property="og:url"
              content="https://example.com/"
          >

E) Uso de Twitter Cards

Las Twitter Cards permiten establecer metadatos para controlar la forma en que una página puede presentarse al ser compartida en Twitter.

En este ejemplo se utiliza una tarjeta del tipo summary_large_image. 

          <meta
              name="twitter:card"
              content="summary_large_image"
          >

          <meta
              name="twitter:site"
              content="@usuario"
          >
